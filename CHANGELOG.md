# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2026-08-02

### Added
- **Supabase Integration**: Migrated from local storage to a robust Supabase backend for database and real-time syncing.
- **User Authentication**: Implemented secure user login and registration flows.
- **User Onboarding**: Added a comprehensive onboarding walkthrough for new users.
- **Task Management Menu**: Added a dedicated tasks menu with advanced views (including the new Calendar view).
- **Task Assignment**: Users can now assign tasks to themselves or team members.
- **Notifications**: Integrated real-time system notifications and toast alerts for task assignments and comments.
- **Image Upload**: Added capabilities to upload images (e.g., for user profiles and task attachments).

### Changed
- **Dashboard Revamp**: Completely redesigned the dashboard page for a more premium, bento-grid aesthetic and better UX.
- **Landing Page Revamp**: Overhauled the landing page with Framer Motion animations and interactive mockups.
